# Answers

## Filename

`ANSWER-<lane>-<n>.md`. Matches `QUESTION-<lane>-<n>.md`.

## Contents

1. beds: behavior tables (input -> observed output).
2. numbers: offsets, sizes, counts, timings.
3. verdict: answered / partial / dead-end. Dead ends say why.

## Rules

- Derived, never transcribed. No spec quotes, no header dumps, no code.
- Link sources (fetch-verified URLs only). Brief summaries.
- Mark unsure UNRESOLVED. Never assert guesses.

## Memo agents

Poll `tmp/queries/` for open questions. Mine memos. Never idle.
Never re-run dead models unchanged. File answers here, update JOBS.md.
