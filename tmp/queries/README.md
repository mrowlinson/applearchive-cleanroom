# Query mailbox

Lanes file here before giving up on any cell.
Re-check `../hints/answers/` before finalizing.

## Filename

`QUESTION-<lane>-<n>.md`. Example: `QUESTION-aar-hdr-3.md`.

## Fields

1. cell: what byte range / behavior is stuck.
2. need: exact question. Behavior-only.
3. tried: what probes ran, with numbers.
4. exhibits: own observed bytes / commands. No proprietary text.

## Rules

- Behavior-only. No pasted specs, headers, reference code.
- 1 question per file. Number sequentially per lane.
- Leave file in place after answer lands (provenance).
