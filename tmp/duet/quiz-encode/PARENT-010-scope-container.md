Deliverable = container ONLY (framing, blocks, headers, entry
kinds, codec selection, AEA envelope). Codecs are NOT
reimplemented on sight. Rules:

1. LINK (OSS/system) wherever byte-identical to oracle. The
   bed-war (OSS-vs-oracle byte checks) is the determination
   step — correct, continues. Link needs PARENT-003 gates
   (survey + pin + sweep byte-verify).
2. REWRITE a codec only with (a) viewer proof of oracle-vs-OSS
   divergence or proprietary format, + (b) parent sign. No
   sign = no rewrite. Bed-war first, always.
3. w1 own-XZ: ships ONLY with divergence proof + sign. Until
   then it is a spike, not the path. 9433954 stays held (RED
   + PARENT-008 gates unchanged).
