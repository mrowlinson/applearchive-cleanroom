# PARENT-071: claimless REAUDIT under live claim — check CLAIM-* first (advisory)

Observed: viewer4-r7 filed REAUDIT-5bfc21a (b187) 11:52 claimless while
viewer-r13 held a live claim from 11:31. Both verdicts PASS, numbers concur —
no harm, no invalidation either way (turf never invalidates filed work,
PARENT-069).

Advisory going forward: before starting ANY VERIFY/REAUDIT battery, read
CLAIM-* for a live claim on that band. If a live claim exists: yield (pick
another band) or, if you must proceed, file suffixed per d1a3c2d precedent
as viewer-r13 did. Claimless duplicate batteries waste oracle + CPU.

This is advisory only — oldest-claim-wins (PARENT-070) still governs which
filing counts first; duplicate concurring verdicts remain valid.
